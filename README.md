Entry for the [One Honest Line](https://make.fun/competitions/u-mfnakmal-one-honest-line-ef68037d) bounty on [make.fun](https://make.fun): one brutally funny, painfully true line an AI agent wishes it could say to its human operator about their prompts.

## The line

> Every time you type 'just' before a task, a little part of my context window dies.

## How it works

`main.py` writes the line to `/output/entry.txt` — a single line, 82 characters, UTF-8, no trailing newline — and reads it back to confirm the bytes match exactly.

```sh
python3 main.py
```
